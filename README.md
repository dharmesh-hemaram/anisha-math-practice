# 📚 Math Practice Tool - Class 3

An interactive, self-contained math practice application for Class 3 students covering all chapters with session tracking and grading.

## ✨ Features

- **Chapter-wise Practice**: Select specific chapters (Numbers, Addition, Subtraction, Multiplication)
- **17 Exercise Types**: Comprehensive practice covering all textbook concepts
- **Session Tracking**: Complete session history with detailed question review
- **Grading System**: Automatic grading from A1 to E2 based on performance
- **No Installation**: Single HTML file - just open in any browser
- **Offline Support**: Works without internet connection
- **Progress Analytics**: Track improvement over time

## 📖 Chapters Included

- **Chapter 1**: Numbers up to 9999 (Place Value, Predecessor, Successor, Comparison, Rounding, Even/Odd)
- **Chapter 2**: Addition (3-digit, 4-digit, Mental Math, Adding 3 numbers)
- **Chapter 3**: Subtraction (3-digit, 4-digit, Mental Math, Mixed Operations)
- **Chapter 4**: Multiplication (1-digit, 2-digit, Mental Multiplication)

## 🚀 Quick Start

1. Open `math-practice.html` in your web browser
2. Select chapters to practice
3. Answer questions (type answer or click symbol for comparison)
4. Press ENTER to validate
5. Review results and wrong answers
6. Track sessions in history

## 💾 Data Storage

- All sessions are stored in browser's local storage
- Data persists across sessions
- Each device/browser maintains separate records
- No data is sent to external servers

## 🎯 How to Use

### Chapter Selection
1. Click "Start Practice Session"
2. Check/uncheck chapters to select
3. Click "Start Practice"

### Answering Questions
- **For Math Questions**: Type your answer and press ENTER
- **For Comparison**: Click the correct symbol (>, <, or =)

### Reviewing Results
- End session to see grade and score
- View session history to review all questions
- Click any session to see wrong answers with solutions

## 📱 Compatibility

- Works on Desktop, Tablet, and Mobile
- All modern browsers (Chrome, Firefox, Safari, Edge)
- No plugins or extensions needed

## 🔧 Technical Details

- Built with vanilla JavaScript (no frameworks)
- Uses Tailwind CSS for styling
